migracao. A remocao total do legado Node ainda depende da janela formal da
Fase 17, mas a documentacao e os contratos canonicos ja podem apontar para a
parte Python.

## Indices disponiveis

- `docs/migration/archive/legacy-golden-index.md`
- `docs/migration/archive/migration-policy.md`

## Referencias preservadas

- `tests/fixtures/legacy-golden/` continua como base historica dos goldens Node.
- `docs/migration/evidence/` preserva as evidencias por fase.
- Os contratos novos e os testes de rotina devem apontar para Python como fonte
  canonica sempre que possivel.
